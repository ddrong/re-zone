# 정비ON AI — 모바일 UI 시연 프로젝트

기존 대화에서 확정한 메인 및 서브페이지 시안의 톤(민트·딥네이비, 부드러운 그림자, 둥근 버튼, 마스코트)을 React/Vite로 재구성한 **수정 가능한 소스코드**입니다.

## 실행

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 URL에 접속하세요.

## 화면

- 홈: 관심 구역 알림, 최근 매물, 예산 탐색, 시세 카드, 부산 현황
- 지역 탐색: 검색, 재개발·재건축 탭, 지도 자리표시자, 관심 등록
- 구역 상세: 8단계 진행 시각화, 요약, 관심 등록, 연결된 매물
- 관심/알림: 관심 구역, 변경 내역, 읽음 상태
- 수익 분석: 비용 입력 및 보수·기준·낙관 시뮬레이션
- MY: 계정 연결 예정, 알림 유형 토글 및 관심구역 관리

## 시안 이미지

`design-references/` 폴더에 화면별 승인 전 이미지 시안을 넣었습니다. Codex에 이 폴더와 현재 구현 코드를 함께 전달하세요.

## 중요: 시연용이며 실제 서비스 데이터가 아닙니다

가상 구역명·가격·상태·경매 내역을 이용합니다. 지도는 데이터 연동 전 추상 스타일이며, 실제 행정 경계 지도나 정식 부동산 사진이 아닙니다. 수익 계산은 단순 시나리오 예시로 실제 투자 조언이나 예측이 아닙니다.

- Supabase Auth/DB 미연결
- 실거래가 API, 매매·경매 실데이터 미연결
- 카카오톡 메시지·실제 웹 푸시 미연결
- 토글·찜·알림 읽음 상태는 새로고침 후 유지되지 않음
- 카카오 발송은 연동 승인 전 반드시 서버에서 차단할 것
