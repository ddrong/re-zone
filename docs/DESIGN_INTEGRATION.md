# 정비ON AI 원본 디자인 통합

## 공식 디자인 기준

GitHub feat/jeongbion-ui-prototype 브랜치의 4cf3733 커밋을 사용한다.
prototypes/jeongbion-ui는 원본 React/Vite 프로젝트와 design-references 보관본이다.
브랜치를 병합·전환하지 않고 해당 경로의 파일만 복원했다.

src/components/prototype-views.jsx는 원본 Section·Pill·StageTrack와 7개 화면 컴포넌트를 재사용한다.
src/app/prototype.css와 public/assets/oni.png는 원본과 바이트 단위로 동일하다.
src/app/integration.css는 인증·공식 자료·카카오맵·브랜드와 1920px 반응형을 보완한다. 원본 CSS 파일 자체는 유지한다.
모바일 하단 메뉴와 민트·딥네이비 토큰, 둥근 버튼·그림자·온이 마스코트를 유지한다.

## 화면과 인증

- /: 공식자료 통계·구군 현황과 회원별 관심지역을 연결한 PC/모바일 대시보드.
- /areas: 부산 16개 구·군 공식 공개자료 검색. 시연 자료는 별도 탭.
- /zones/[id]: 공식 구역 또는 원본 시연 구역 상세.
- /favorites, /alerts: 인증된 회원별 관심지역·알림 DB 조회 화면. DB 미준비 시 오류/준비 상태 표시.
- /analysis: 원본 가정 기반 계산기. 실제 예측·투자 추천이 아니다.
- /my: 원본 MY와 실제 이메일 계정 연결부.
- /account: 기존 회원별 관심지역 저장·해제.
- /login, /signup: 기존 이메일 인증과 Kakao OAuth·PKCE 처리.
- 공식 구역의 관심 버튼은 실제 회원별 관심지역 관리로 이동한다. 시연 찜과 섞어 저장하지 않는다.

운영 인증 복귀·로고·폰트·카카오맵 준비와 실제 테스트 절차는 [운영 수정 안내](RELEASE_FIXES.md)를 따른다.

Prisma 모델·환경변수·인증 설정은 변경하지 않는다.
DB 적용과 인증 변수 등록은 기존 승인 절차를 따른다.
실제 회원 생성·DB 쓰기 테스트는 이번 작업에 포함하지 않는다.

## 실제 공공자료 연계

출처: 부산광역시 정비사업 통합홈페이지
https://dynamice.busan.go.kr/view.do?no=273
https://dynamice.busan.go.kr/view.do?no=274

공식 사이트의 공개 목록과 그 화면이 사용하는 공개 상세 조회를 서버에서 읽는다.
공공데이터포털의 인증키 기반 정식 OpenAPI를 연결했다고 표현하지 않는다.
공식 데이터 다운로드 링크의 부산 데이터포털 페이지는 확인 당시 오류로 접근하지 못했다.

서버는 고정된 공식 호스트만 요청하고 검색어 길이·지역·유형·페이지를 검증한다.
10초 시간 제한과 응답 크기 검사, 최대 1시간 조회 캐시를 적용한다.
HTML은 화면에 주입하지 않고 필요한 텍스트 필드만 추출한다.
담당자·연락처·등록자·회원 정보 등 불필요한 필드는 전달하지 않는다.
원본이 바뀌거나 조회가 실패하면 오류를 표시하고 가상 자료로 자동 대체하지 않는다.

목록은 유형별 공개 페이지를 순회해 중복 제거 후 앱에서 검색·페이지 처리한다. 유형별 최대 40페이지이며 일부 실패·한도 도달 시 부분 집계로 표시한다. 지역별 건수는 같은 수집 목록 기준이다.
공식 단계명을 원본 8단계 안내에 대응하며 미확정·해제는 단계 번호를 만들지 않는다.
원본 갱신일과 우리 앱의 조회 시각은 구분한다. 조회 시각이 최신성 보장은 아니다.
이 연계는 원본 사이트 구조에 의존하므로 운영 전 안정적 제공 방식·이용 조건을 제공기관과 확인한다.
부산 전체 건수, 실매물·실가격·수익률은 임의 생성하지 않는다.

## 검증

npm run typecheck
npm run lint
npm run build
node scripts/check-design-parity.mjs

디자인 비교 검사는 승인된 개별 시연 안내 추가를 제외하고 원본 홈·상세·관심·알림·계산기의 구조적 클래스를 비교한다.
원본 CSS·마스코트는 별도 바이트 비교한다. 이는 실제 브라우저 화면의 픽셀 비교와 다르다.
브라우저 연결이 없는 경우 모바일 배치·클릭·키보드·스크린샷은 미검증으로 보고한다.

## 7대 기능 후속 수정

최신 구현·검증·설정 및 미완료 사항은 [7대 기능 검사 결과](CORE_FUNCTION_REVIEW.md)를 따른다. 수익 계산기는 초기값·초기화가 모두 빈칸이며 입력 전 결과는 —다. 실제 DB/환경변수 값 변경이나 배포는 하지 않았다.
