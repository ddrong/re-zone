# 정비ON AI

프로젝트를 시작하기 전에 [docs/SETUP.md](docs/SETUP.md)를 먼저 읽으세요.

## 프로젝트 개요

- **한 줄 소개:** 부산의 재개발·재건축 정비사업 정보를 검색하고, 관심지역 관리와 투자 수익 분석을 지원하는 AI 기반 부동산 정보 웹앱입니다.
- **누구를 위한 앱인가:** 재개발·재건축에 관심 있는 일반 시민, 부동산 투자자, 공인중개사, 부동산 관련 학과 학생을 위한 서비스입니다.
- **어떤 상황에서 쓰는가:** 부산의 정비사업 구역과 추진 현황을 확인하거나 관심지역을 관리하고, 예상 투자비용과 수익을 분석할 때 사용합니다.

## 주요 기능

| 과제의 꼭 있어야 하는 기능 | 화면(프론트엔드) | API(백엔드) |
| --- | --- | --- |
| 1. 정비사업 정보 검색 | 부산 구·군별 검색, 재개발·재건축 필터, 구역 목록 및 상세정보 | 부산시 공식 정비사업 공개자료 조회 및 검색 기능 |
| 2. 회원가입 및 관심지역 관리 | 로그인·회원가입, 관심지역 등록, 즐겨찾기, MY 페이지 | Supabase 사용자 인증 및 관심지역 데이터 관리 |
| 3. 투자 수익 분석 | 매입가격·추가분담금·비용 입력, 예상 손익 및 수익률 표시 | 사용자 입력값 검증 및 수익 계산 처리 |

**더 만든 기능:**

- 정비ON 브랜드 로고와 마스코트 '온이'를 활용한 UI
- 부산 지역별 정비사업 현황 대시보드
- 사업 추진단계 시각화
- 관심지역 알림 및 매물 정보 화면
- 수익 분석 시나리오 비교
- 모바일 중심 반응형 디자인
- GitHub와 Vercel을 이용한 웹사이트 배포

**추가 개발 및 개선 중인 기능:**

- 카카오 간편가입 및 로그인
- 카카오맵을 이용한 정비구역 위치 표시
- 실제 공식자료 검색 정확도 개선
- 로그인 사용자별 관심지역 정보 저장
- PC 디자인 복원 및 반응형 최적화
- AI도우미 챗봇, FAQ, 음성 입력 및 상세페이지 이동

## 기술 스택

- **프론트엔드:** Next.js, React, TypeScript, Tailwind CSS, HTML, CSS
- **백엔드:** Next.js 서버 기능, Node.js, Supabase Authentication, Prisma
- **데이터(어디에, 무엇을):**
  - Supabase PostgreSQL: 사용자 정보와 관심지역 등 서비스 데이터
  - Supabase Auth: 회원가입, 로그인, 사용자 인증
  - 부산광역시 정비사업 공식 공개자료: 재개발·재건축 구역 및 추진 현황
  - 시연 데이터: UI 테스트를 위한 예시 매물 및 가격 정보

## 실행 방법

1. GitHub에서 프로젝트를 내려받습니다.

   ```bash
   git clone https://github.com/ddrong/re-zone.git
   cd re-zone
   ```

2. VS Code에서 프로젝트 폴더를 열고 터미널에서 필요한 패키지를 설치합니다.

   ```bash
   npm install
   ```

3. `docs/SETUP.md`를 참고하여 필요한 환경변수를 설정한 후 개발 서버를 실행합니다.

   ```bash
   npm run dev
   ```

   브라우저에서 아래 주소로 접속합니다.

   http://localhost:3000

   ※ 데이터베이스와 로그인 등 일부 기능은 Supabase 환경변수 설정이 필요합니다.

https://jeongbi-on.vercel.app

https://github.com/ddrong/re-zone

  > ２번. 카카오맵 연동안됨。카카오맵을 연동하시오.

  **프롬프트 3 — 실제 데이터 검색**

  > 3번. 검색기능 안됨. 실제 공개자료를 불러올것.
