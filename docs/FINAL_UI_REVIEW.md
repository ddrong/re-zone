## 변경

- 상세 하트는 스크롤, 목록 하트는 상세 이동만 하던 연결을 실제 Server Action 호출로 교체했다.
- official-zone-favorite.tsx의 공통 Provider와 버튼으로 목록·상세의 저장 상태를 공유한다. 동시 클릭을 막고 저장·해제 후 private/no-store 계정 API를 재조회한다. 읽기·쓰기 실패를 표시하며 임의 성공 상태를 만들지 않는다.
- 기존 서버의 getMember 검증, 공식 BARA ID 검증, 공식 원문 재조회, 트랜잭션 upsert, 회원별 deleteMany/updateMany 소유권 조건을 재사용한다. 로그인 전에는 현재 경로를 보존해 로그인으로 이동한다.
- MY·관심 화면의 기존 DB 목록과 연결한다. 비회원 화면에 이메일 로그인 진입도 제공한다.
- 가상자료 탭과 mode=demo 분기, 가상 ID 상세 진입을 제거했다. 미사용 가상 홈·상세·알림·매물 화면 구현을 정리하고 운영 모듈의 prototype-data 참조를 제거했다. 원본 Vite 보관본과 테스트 자료는 보존했다. 과거 DB 카탈로그의 가상 자동 대체도 빈 결과/실패 상태로 변경했다.
- 공식 상세의 이름·유형·주소·면적·갱신일·출처, 8개 UI 단계 그룹, 지도 카드, 공통 관심 CTA를 구성했다. 단계 그룹은 법적 단계 확정이나 진행률이 아니다.
- 공통 Pill 버튼·포커스·빈 상태·카드와 모바일 계산기 입력 너비 및 단위 줄바꿈을 보완했다. 계산식·초기화 기능은 유지했다.
- 지도 렌더링·키 전달·환경변수·인증·Prisma 스키마·이미지·README는 변경하지 않았다.

- 로컬 프로덕션 HTTP: 홈·공식 목록·공식 상세·로그인·회원가입·계산기·MY·관심 200. mode=demo에도 공식 가야1 조회. 가상 /zones/u는 not-found/noindex 처리(스트리밍으로 HTTP 200일 수 있음). 공식 상세에 공통 관심 버튼 3개·지도 영역 존재. 비회원 API는 authenticated=false, private/no-store.

- 변경 코드의 로컬 변수 값 대조 및 비밀정보 패턴 검사 통과. .env.local Git 제외 확인.
