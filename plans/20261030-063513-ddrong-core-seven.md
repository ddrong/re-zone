# 정비ON AI 7대 핵심 기능 수정

작성자: ddrong
기준: main / bb7321a
승인: 첨부 7대 기능 지시서의 코드 수정 요청, 사용자 계획 파일 작성 승인. 기존 웹앱 구현의 사전 전체 코드 제시 생략 승인 범위에서 진행.

## 목표와 순서

1. 기존 Supabase 서버 클라이언트로 Kakao OAuth와 안전한 PKCE 콜백 재사용.
2. 카카오 지도 새 키 이름 지원, 기존 키 호환, SDK 로딩·실패 처리. 로컬 실제 값은 변경하지 않음.
3. 공식 목록 페이지 순회·중복 제거·정규화 검색, 구역명/주소/유형/구군/단계 복합 필터, 동일 자료 기준 건수.
4. 홈·관심·알림을 세션 소유자 DB 조회에 연결. 가상 개인화 제거. 기존 관심지역 저장/해제 및 설정 수정 재사용.
5. 계산기 최초/초기화 모든 금액 빈칸, 유효하지 않으면 결과 —, 만원 단위 검증.
6. 원본 로고/온이/민트/딥네이비/Noto 유지, PC 대시보드와 모바일 세로 카드.
7. 타입·린트·서식·빌드·인증 모의·공식 HTTP·가능한 브라우저 검증.

## 수정 대상과 책임

- src/app/auth 및 auth-form/kakao-login: 인증만 담당. 반환 경로 공통 검증 재사용.
- src/lib/public-zones, api/public-zones, public-explorer: 공식 수집/검증/표시 분리.
- api/account, personal-regions, account/actions, favorite-form: 인증된 소유자 조회와 쓰기 조건만 담당.
- calculator, prototype-shell/views: 입력과 순수 계산 분리.
- dashboard-home, integration.css: 공식 자료 기반 홈과 반응형 레이아웃.
- .env.example, docs: 변수 이름과 사용자 설정 안내. .env.local 보존.

## 영향·위험·제한

실제 DB 구조·마이그레이션·데이터 변경 테스트·환경변수 값 변경·Git 커밋/푸시·배포는 실행하지 않음. 기존 데이터 보존. 공식 사이트 페이지 구조에 의존하고 한 시간 캐시, 유형별 최대 40페이지 제한 및 부분 조회 표시. 공유 DB 사용자·알림 조회는 인증 ID로 제한하고 공개 캐시 금지. Prisma 연결은 RLS를 대신하지 않음. 기존 schema는 구역 찜 모델이 없고 User.email 필수이므로 구역 찜·이메일 미제공 프로필 저장은 모델/DB 별도 승인 필요.

브라우저 연결 발견 결과 없음. 실제 OAuth/지도 키/가입·DB 쓰기 및 여섯 해상도 클릭·픽셀 검증은 수행할 수 없으면 미검증으로 보고. 첨부 PC 이미지 없음; 저장소 원본 자산 기준. 기존 KRDS 전체 준수 주장 없이 폼 라벨·키보드 포커스·로딩·오류·빈 상태 기준을 적용. 폰트 변경 없음. 현재 작업 트리와 plans에서 중복 계획 없음, 미공유 브랜치는 확인 한계.

## 최신 상태

구현 진행 중. 최종 검사 후 명령·결과·남은 설정 갱신 예정.

## 후속 검사 결과

타입·ESLint·프로덕션 빌드 성공. 인증/계산기·검색/소유권 모의 검사와 원본 CSS/온이 비교 성공. 실제 HTTP 가야1(관리처분계획), 가야3(준공) 검색 및 복합 필터 통과. DB 읽기 전용 검사에서 필수 테이블 없음/BYPASSRLS 역할 확인. 실제 DB 쓰기/정책 적용 없음. 로컬 인증·지도 공개 변수 없음. 사용자는 브라우저 검사 없이 진행 선택. 6개 해상도·실제 OAuth·SDK·저장 복원 미검증. npm run check는 기존 35개 파일 서식 경고로 실패, 새 변경 파일은 별도 검사. 상세 결과와 수정 파일은 docs/CORE_FUNCTION_REVIEW.md 참고. README 사용자 변경·스테이징 보존. 최종 Git·배포 승인은 받지 않았고 실행하지 않음.

## 12개 모델 로컬 반영 승인 후

사용자는 로컬 모델·연결 코드 반영만 승인하고 실제 DB 적용은 승인하지 않았다. User.email nullable, FavoriteZone·NotificationPreference와 회원별 서버 처리/조회/폼을 연결했다. Prisma 검토 모델과 차이 없음. 스키마·타입·린트·빌드 및 메모리 A/B 저장/복원/소유권 검사 통과. 실제 DB 쓰기·정책 검증은 미실행. 사용자 이미지 4개 보존, 원본 oni 바이트 비교는 사용자 이미지 변경으로 불일치. 로컬 지도 허용 주소는 아직 미확인(사용자 답변은 운영 URL). Git·배포 미실행. 상세: docs/FOUR_FEATURE_COMPLETION.md.
